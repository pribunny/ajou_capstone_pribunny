# Pribunny
<img src=https://github.com/user-attachments/assets/ea5655fc-1744-4a30-8d5e-648be5f344ed>

개인정보처리방침 및 개인정보 수집·이용 동의서를 더 쉽게 이해할 수 있도록 도와주는 개인정보보호 도우미입니다.

사용자는 복잡하고 긴 개인정보 문서를 그대로 읽기 어렵습니다.  
**PriBuddy**는 문서를 분석해 핵심 내용을 요약하고, 사용자에게 불리하거나 모호할 수 있는 조항을 탐지하여 개인정보를 더 주체적으로 관리할 수 있도록 돕습니다.

---

## 프로젝트 소개

PriBuddy는 다음과 같은 문제를 해결하기 위해 기획되었습니다.

- 어려운 법률/전문 용어 때문에 개인정보 문서를 이해하기 어려움
- 긴 약관과 동의서를 제대로 읽지 않고 넘어가기 쉬움
- 과도한 개인정보 수집이나 불공정한 조항을 놓치기 쉬움

이를 해결하기 위해 PriBuddy는 개인정보 문서를 **쉽게 요약**하고, **위험하거나 불공정할 수 있는 조항을 탐지**하는 기능을 제공합니다.

## 주요 기능

### 1. 개인정보 문서 요약
- 개인정보처리방침 및 수집·이용 동의서 내용을 항목별로 요약
- 어려운 법률 용어를 이해하기 쉬운 표현으로 정리

### 2. 불공정 조항 탐지
- 사용자에게 불리하거나 모호한 조항 탐지
- 관련 법률/가이드라인을 참고해 탐지 결과 제공

### 3. 다양한 입력 방식 지원
- **크롬 확장 프로그램**: 웹페이지를 직접 분석
- **웹사이트**: PDF 또는 이미지 파일 업로드 후 분석
- **선택 텍스트 분석**: 드래그한 텍스트만 빠르게 분석

### 4. 사용자 맞춤형 결과 제공
- 사용자가 관심 있는 항목을 우선적으로 확인 가능
- 원하지 않는 개인정보 수집 항목을 강조 표시 가능

## 시스템 구조

PriBuddy는 아래와 같은 구조로 동작합니다.

- **Front-End**
  - 크롬 확장 프로그램
  - 웹사이트 UI
- **API Server**
  - 입력 데이터 전처리
  - 문단 분리 및 항목 분류
  - LLM 서버와 통신
- **LLM Server**
  - 요약 생성
  - 불공정 조항 탐지
  - RAG 기반 관련 법률 문서 참조

사용자가 웹페이지 또는 파일을 입력하면, 시스템이 텍스트를 추출하고 분석한 뒤 결과를 사용자에게 보여줍니다.

## 기술 포인트

- **LLM 기반 문서 요약**
- **RAG 기반 불공정 조항 탐지**
- **PDF / 이미지 OCR 처리**
- **웹페이지 HTML 파싱**
- **크롬 확장 프로그램 + 웹 서비스 연동**

## 기대 효과

- 개인정보 보호를 위한 능동적 의사결정 지원
